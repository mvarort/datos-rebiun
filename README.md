# REBIUN Data Explorer

**Aplicación pública:**  
https://mvarort.github.io/datos-rebiun/

**REBIUN Data Explorer** es una aplicación web estática para consultar, comparar y visualizar estadísticas de la Red de Bibliotecas Universitarias y Científicas Españolas (REBIUN).

Permite combinar bibliotecas, años e indicadores, generar tablas longitudinales y explorar los resultados mediante gráficos de evolución y comparación. La aplicación funciona íntegramente en el navegador y se publica mediante GitHub Pages.

## Datos disponibles

La versión actual integra las campañas **2020–2025**.

| 2021 | 9.490 | 130 |
| 2022 | 10.439 | 143 |
| 2023 | 12.168 | 156 |
| 2024 | 12.168 | 156 |
| 2025 | 12.558 | 161 |

El fichero longitudinal contiene **65.925 registros** y el directorio institucional reúne **78 bibliotecas o instituciones REBIUN**.

## Funcionalidades

### 1. Bibliotecas

Las bibliotecas pueden seleccionarse y filtrarse mediante:

- código oficial REBIUN y denominación;
- comunidad autónoma;
- modalidad;
- titularidad;
- buscador por código o nombre;
- selección individual o en bloque;
- segmentador dinámico por tamaño.

El código oficial REBIUN se muestra delante del nombre de cada institución, por ejemplo:

## Fuente de las siglas institucionales

Las siglas de las universidades proceden del Registro de Universidades, Centros y Títulos (RUCT). Como única excepción, el Consejo Superior de Investigaciones Científicas se identifica mediante la sigla **CSIC**, que no procede del RUCT al no tratarse de una universidad.
