# Datos REBIUN

**Consulta, generación y descarga de estadísticas REBIUN**

### Aplicación

https://mvarort.github.io/datos-rebiun/


Aplicación web para consultar, seleccionar y reutilizar de forma sencilla las estadísticas de las bibliotecas universitarias y científicas españolas recogidas por REBIUN.

## Funcionalidad principal

El selector permite construir consultas personalizadas combinando años, bibliotecas, características institucionales e indicadores.

Como principal mejora, la aplicación permite generar dinámicamente tablas personalizadas y descargar en CSV exclusivamente los datos seleccionados para su reutilización y análisis posterior.

Entre sus funciones se encuentran:

- selección de años, bibliotecas e indicadores;
- filtros por comunidad autónoma, modalidad y titularidad;
- selección por eje y apartado REBIUN;
- generación dinámica de tablas;
- organización de resultados por año, biblioteca o indicador;
- descarga de los datos seleccionados en CSV;
- consulta longitudinal de varias campañas en una única aplicación.

## Cobertura temporal

Actualmente se integran las campañas 2020, 2021, 2022, 2023, 2024 y 2025.

Las campañas 2020-2024 se contrastan con los ficheros actualmente publicados por REBIUN.

Los datos de 2025 proceden de la fuente de trabajo disponible y se actualizarán cuando REBIUN publique la versión definitiva de la campaña.

## Funcionamiento

La aplicación es completamente estática y se ejecuta en el navegador. Los datos longitudinales se almacenan en CSV, sin necesidad de servidor, base de datos ni instalación adicional.

## Estado del proyecto

Versión inicial funcional preparada para demostración.

El proyecto dispone actualmente de datos longitudinales 2020-2025, normalización de bibliotecas, segmentadores relacionados, generación de tablas personalizadas, descarga en CSV y mecanismos de comprobación y actualización segura de las fuentes.

## Próximas mejoras

- automatización completa de las actualizaciones;
- incorporación automática de nuevas campañas;
- tratamiento de cambios históricos en la numeración y denominación de indicadores;
- ampliación de los controles de calidad;
- mejoras de interfaz y visualización;
- documentación metodológica.

## Fuentes

Los datos proceden de las campañas estadísticas de REBIUN (Red de Bibliotecas Universitarias y Científicas Españolas).

https://www.rebiun.org/estadisticas/observatorio-publico-estadistico/campanas-en-excel

## Aviso

Este proyecto es una herramienta de consulta y reutilización de datos y no constituye una aplicación oficial de REBIUN.
